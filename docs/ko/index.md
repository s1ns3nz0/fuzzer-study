# 퍼징으로 읽는 보안 감사

!!! warning "집필 중"
    이 교재는 현재 골격만 세워진 상태입니다. 모든 장이 작성·검증을 거친 뒤 공개됩니다.

## 이 교재가 주장하는 것

`ffuf` 로 숨은 경로를 찾는 일, `Schemathesis` 로 API 스펙을 두드리는 일,
`forge` 로 컨트랙트 불변식을 깨는 일. 셋은 도구도 다르고 커뮤니티도 다르고
"퍼징"이라는 단어가 뜻하는 바도 미묘하게 다릅니다.

그런데 셋 다 같은 일을 합니다. **너무 커서 다 볼 수 없는 입력공간을,
유한한 시간 안에, 버그가 있을 법한 쪽으로 편향되게 탐색하는 일.**

이 교재는 그 공통 구조를 다섯 개 요소로 분해하고, 세 도메인이 같은 요소를
각자 어떻게 구현하는지를 따라갑니다.

| 요소 | 묻는 질문 |
|------|-----------|
| **생성** | 입력을 어디서 가져오는가 |
| **변이** | 가진 입력을 어떻게 비트는가 |
| **오라클** | 무엇을 버그라고 부르는가 |
| **피드백** | 결과를 보고 다음 입력을 바꾸는가 |
| **커버리지** | 얼마나 봤는지 어떻게 아는가 |

도구를 배우는 책이 아닙니다. 도구는 3년 뒤에 바뀝니다. 다섯 요소는 안 바뀝니다.

## 독자 전제

- HTTP, `curl`, 터미널, Docker 를 씁니다
- 아무 언어로든 프로그래밍을 합니다
- 퍼징은 처음입니다
- Solidity 와 스마트컨트랙트도 처음입니다 (Part 3 에서 필요한 만큼만 깝니다)

## 문서 신뢰 정책

이 교재에 실린 명령어는 **전부 실제로 실행해 출력을 확인한 것**입니다.
실행되지 않은 명령어는 게재하지 않습니다. 각 장 하단의 「검증 로그」에
검증 일자·도구 버전·환경이 기록됩니다.
