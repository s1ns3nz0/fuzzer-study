# 랩 환경

파트별로 `docker-compose.yml` 하나씩. 장마다 새 환경을 만들지 않고 공유합니다.

| 디렉토리 | 파트 | 타겟 | 상태 |
|----------|------|------|------|
| `web2/` | Part 1 (4–7장) | 자체 제작 취약 웹앱 | ✅ 동작 확인 |
| `api/` | Part 2 (8–11장) | VAmPI | 미제작 |
| `web3/` | Part 3 (12–15장) | damn-vulnerable-defi + anvil | 미제작 |

## 공통 규칙

- 모든 포트는 `127.0.0.1` 에만 바인딩합니다. 인터넷에 노출하지 마십시오.
- 컨테이너는 의도적으로 취약합니다. 운영 네트워크에 붙이지 마십시오.
- 실습 후 `docker compose down` 으로 내립니다.
